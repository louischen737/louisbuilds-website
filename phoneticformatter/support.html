Getting Started

Phonetic Formatter converts English text into rule-based IPA transcription. All processing is performed locally on your device.

Basic Workflow

  1. Enter or paste English text into the input field.
  2. Select the display format:
    • Sentence-level transcription
    • Word-aligned transcription (Pro)
  3. (Optional) Configure left and right IPA wrapping symbols.
  4. Tap Generate to produce phonetic output.
  5. Copy results directly, or export (Pro) in supported formats.

Usage Limits

Free Version

  • Sentence-level transcription only
  • Up to 400 words per conversion
  • One generation per day

Pro Version (One-Time Purchase)

  • Sentence-level and word-aligned transcription
  • Up to 6,000 words per conversion
  • Unlimited generations
  • Export support (TXT, DOCX, PDF)

Technical Overview

Phonetic Formatter is a deterministic, rule-based IPA formatting engine designed for accurate processing of real-world English text.

Core characteristics:

  • Rule-based sentence boundary detection
  • Context-aware tokenization (punctuation, quotation marks, hyphen variants, numeric formats)
  • Support for signed numbers and percentage forms
  • Unicode-aware text normalization
  • Fully offline processing
  • Powered by the CMU Pronouncing Dictionary (Carnegie Mellon University)
  • Output rendered using the International Phonetic Alphabet (IPA)

All transcription results are generated locally. No text is uploaded or transmitted.

Exporting Results

Pro users may export generated transcription results in the following formats:

  • TXT — Plain text format
  • DOCX — Microsoft Word document format
  • PDF — Portable Document Format

To export:

  1. Generate transcription output.
  2. Tap Export.
  3. Select the desired format from the system share sheet.
Note: Available export destinations depend on device configuration and installed applications.

Frequently Asked Questions

What is the difference between Free and Pro?▼

The Free version provides sentence-level transcription with usage limits. The Pro version removes daily limits, enables word-aligned transcription, and allows exporting results in multiple document formats.

How do I upgrade to Pro?▼

Upgrade is available within the app. Navigate to Settings and select Upgrade to Pro to complete the one-time purchase.

Can I restore my Pro purchase on another device?▼

Yes. Use the Restore Purchase option in Settings. Ensure you are signed in with the same Apple ID used for the original purchase.

Does the app require an internet connection?▼

No. All transcription processing is performed locally on the device. No internet connection is required.

Is any user data collected?▼

No. The application does not collect, store, or transmit user text. All processing remains entirely on-device. See the Privacy Policy for details.

What dictionary does the app use?▼

The app is powered by the CMU Pronouncing Dictionary, developed by Carnegie Mellon University. The dictionary is bundled locally to ensure offline availability and consistent transcription behavior.

Does the app support British pronunciation?▼

The current version reflects the pronunciation conventions of the CMU Pronouncing Dictionary, which primarily represents American English phonology. Variant switching is not currently supported.

What is Word-Aligned Transcription (Pro)?▼

Word-aligned transcription presents each lexical item alongside its IPA representation within sentence groupings. This format is suitable for linguistic analysis, annotation, and instructional material preparation.

What are the L and R fields?▼

The L (left) and R (right) fields allow optional wrapping of IPA output (e.g., /həˈloʊ/). Each field accepts up to two characters. Leave both empty to display IPA without wrapping symbols.

Troubleshooting

Transcription is not generated▼

  • Confirm text is entered in the input field.
  • Verify that usage limits have not been exceeded (Free version).
  • Ensure the text is in English.
  • Restart the application if necessary.

Export is unavailable▼

  • Export functionality requires Pro.
  • Confirm transcription output has been generated.
  • Ensure sufficient device storage is available.

Purchase issues▼

  • Use Restore Purchase if the upgrade is not recognized.
  • Confirm you are signed in with the correct Apple ID.
  • For billing or refund requests, contact Apple Support directly.

App crashes or performance issues▼

  • Restart the device.
  • Ensure your iOS version meets App Store requirements.
  • Close background applications to free memory.
  • Reinstall the app if necessary.
  • Contact support if the issue persists.
