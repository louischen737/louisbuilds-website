Politique de confidentialité

Cette politique décrit comment Phonetic Formatter traite vos données personnelles lorsque vous utilisez l’application. En utilisant l’app, vous acceptez les pratiques décrites dans cette politique.

Stockage local des données

Toutes les données sont stockées localement sur votre appareil. Aucun transfert vers des serveurs externes.

Données locales

Peuvent être stockés :

  • Texte saisi et résultats phonétiques
  • État de l’espace de travail
  • Préférences utilisateur
  • Statut d’achat Pro
  • Compteur d’utilisation quotidien (version gratuite)

Vous pouvez effacer toutes les données via « Effacer tous les réglages ».

Aucun transfert vers le cloud

Tout traitement est local. Aucun contenu n’est transféré vers le cloud.

Fonction d’export

L’export utilise le menu partages iOS. Nous n’avons pas accès aux fichiers exportés.

Achats intégrés

La version Pro est un achat unique (licence à vie) via Apple StoreKit. Le paiement est géré exclusivement par Apple. Nous recevons uniquement le statut d’achat, pas vos données de paiement.

Pas d’abonnement : accès permanent sans frais récurrents. Restauration possible via les réglages.

Remboursements selon la politique Apple.

Aucun suivi ni analyse

Aucune collecte de comportement utilisateur. Pas de traceur, pas de publicité.

Pas de services tiers

Aucun service tiers d’analyse ou de publicité.

Suppression des données

Effacez les données via :

  • « Effacer tous les réglages »
  • Désinstallation de l’app
