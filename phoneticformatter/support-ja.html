はじめに

Phonetic Formatter は、英語のテキストを規則に基づく IPA の文字起こしに変換します。音標変換はお使いのデバイス上で行われます。

基本の流れ

  1. 入力欄に英語のテキストを入力または貼り付けるか、あるいはカメラボタンをタップして書類をスキャンするか写真を選び、端末内の OCR で取り込みます（英語のみ、Pro）。
  2. 表示形式を選びます。
    • 文単位の文字起こし
    • 単語ごとの整列（Pro）
  3. （任意）IPA の左右の囲み記号を設定します。
  4. 変換をタップして、音標を出力します。
  5. 結果をそのままコピーするか、対応形式で書き出します（Pro）。

利用の上限

無料版

  • 文単位と IPA のみの形式
  • 1回の変換につき最大400語
  • 1日1回の変換（手入力と OCR を含みます）。結果のコピーはこの回数に含まれません
  • 1日の上限に達したあと、リワード広告を1本視聴すると、その日に限り追加で1回変換できます（1日1回）
  • アプリ内広告が表示されることがあります。広告の読み込みには、通常インターネット接続が必要です
  • 書き出しはできません

Pro（月額サブスクリプションまたは生涯購入）

  • 広告なし。完全にオフラインで動作します
  • 文単位、単語ごとの整列、IPA のみの形式
  • 書類のスキャンとテキスト抽出（OCR）
  • 1回の変換につき最大6,000語
  • 変換回数の制限なし
  • TXT、DOCX、PDF への書き出し

技術概要

Phonetic Formatter は、実際の英語テキストを正確に処理するために設計された、決定的で規則に基づく IPA 整形エンジンです。

主な特徴：

  • 規則に基づく文の区切り検出
  • 文脈を考慮したトークン分割（句読点、引用符、ハイフンの変種、数値の形式）
  • 符号付きの数値と百分率への対応
  • Unicode を考慮したテキストの正規化
  • 音標変換はデバイス上で完全にオフライン
  • 端末内での書類スキャンと OCR によるテキスト抽出（Apple Vision フレームワーク、英語のみ、Pro）
  • CMU Pronouncing Dictionary（カーネギーメロン大学）を使用
  • 出力は国際音声記号（IPA）で表示

入力したテキストと音標の結果が、当社のサーバーにアップロードされることはありません。無料版では、第三者のアプリ内広告（リワード動画など）のためにインターネット接続を使うことがあります。Pro にはアプリ内広告はありません。

結果の書き出し

Pro のユーザーは、生成した文字起こしを次の形式で書き出せます。

  • TXT — プレーンテキスト
  • DOCX — Microsoft Word 文書
  • PDF — Portable Document Format

書き出し手順：

  1. 文字起こしを生成します。
  2. 書き出しをタップします。
  3. システムの共有シートから形式を選びます。
注：書き出し先は、デバイスの設定とインストール済みのアプリによって異なります。

よくある質問

無料版と Pro の違いは何ですか？▼

無料版：
• 1日1回の変換（結果のコピーはこの回数に含まれません）。上限に達したあと、リワード広告を視聴すると追加で1回変換できます（1日1回）
• 1回の変換につき最大400語
• 文単位と IPA のみの形式
• 書き出しはできません

Pro：
• 変換回数の制限なし
• 広告なし
• 1回の変換につき最大6,000語
• 単語ごとの整列、文単位、IPA のみの形式
• テキストのスキャンと取り込み（OCR）
• 使用する発音を選択
• TXT / DOCX / PDF への書き出し

Pro を入手するには？▼

設定 →「Pro を入手」を開きます。月額サブスクリプション（自動更新。Apple のサブスクリプション設定からいつでも解約できます）か、買い切りの生涯購入を選べます。Pro は、サブスクリプションの期限が切れるか返金されるまで有効です。

アプリ内広告を消すには？▼

Pro にアップグレードすると、アプリ内広告がすべて消え、途切れのない音標変換を利用できます。

設定から「Pro を入手」を選び、月額サブスクリプションまたは買い切りの生涯購入でアップグレードできます。

別のデバイスで Pro の購入を復元できますか？▼

できます。購入の流れの中で「購入を復元」が使える場合はそれを使うか、Apple ID から管理してください。最初の購入に使ったのと同じ Apple ID でサインインしていることを確認してください。

どの辞書を使っていますか？▼

北米英語の標準的な参照である CMU Pronouncing Dictionary を使用しています。文の流れと強勢の表示のために、独自の処理を加えています。

イギリス英語の発音に対応していますか？▼

現在のバージョンはアメリカ英語のみに対応しています。イギリス英語にはまだ対応していません。

辞書にない単語はどうなりますか？▼

文単位モード（すべてのユーザーが利用できます）では、CMU 辞書にない単語はそのまま表示されます。
単語ごとの整列モード（Pro のみ）では、見つからない単語はプレースホルダー記号で表示されます。

スキャン / OCR の取り込みはどのように動作しますか？▼

Pro のユーザーは、カメラボタンをタップして書類をスキャンするか写真を選べます。テキストはデバイス上で認識され（英語のみ）、入力欄に挿入されます。文字起こしの前に編集できます。テキストが当社のサーバーに送られることはありません。

単語ごとの整列とは何ですか？▼

単語ごとの整列モードでは、文のまとまりの中で各単語とその IPA が並びます。授業、注釈、学習資料に向いています。Pro のみです。

リーディングビューとは何ですか？▼

リーディングビューは、IPA の結果を全画面で見るモードです。見やすいレイアウト、単語と IPA の対応、文字サイズ、行間、語間を調整できます。出力欄のフッターにあるメガネのアイコンをタップして開きます。

L と R の欄は何のためですか？▼

L（左）と R（右）は、IPA の出力を任意で囲みます（例：/ / や [ ]）。各欄には最大2文字まで入力できます。両方を空にすると、区切りのない IPA になります。

青色の単語は何を意味しますか？▼

青色の単語には、複数の発音があります。青色の単語をタップすると、それらを確認できます。Pro では、表示、コピー、書き出しに使う発音を選べます。

使う発音を選べますか？▼

Pro なら選べます。青色の単語をタップして発音を選んでください。その選択は、その出現箇所の表示、コピー、書き出しに適用されます。

インターネット接続は必要ですか？▼

音標変換はすべてデバイス上で行われます。入力したテキストが当社のサーバーにアップロードされることはありません。

無料版でインターネット接続が必要なのは、第三者サービスによる広告関連の機能（リワード動画など）だけです。Pro にはアプリ内広告がなく、完全にオフラインで動作します。

ユーザーデータは収集されますか？▼

入力したテキストを収集したりアップロードしたりすることはありません。音標処理はすべてデバイス上でオフラインに行われます。

無料版を支えるため、第三者の広告が表示されることがあります。広告のトラッキングを制限したい場合は、iOS の設定（App Tracking Transparency）からいつでも変更できます。Pro は広告なしです。

詳しくはプライバシーポリシーをご覧ください。

トラブルシューティング

文字起こしが生成されない▼

  • 入力欄にテキストが入っているか確認してください。
  • 利用上限を超えていないか確認してください（無料版）。
  • テキストが英語であることを確認してください。
  • 必要であればアプリを再起動してください。

スキャン / OCR でテキストが入らない▼

  • 書類のスキャンと OCR には Pro が必要です。
  • 求められたら、カメラまたは写真ライブラリの許可を与えてください。
  • OCR は英語のテキストのみに対応しています。より鮮明な写真で試すか、もう一度スキャンしてください。
  • 文字起こしを生成する前に、入力欄で認識結果を編集できます。

書き出しができない▼

  • 書き出しには Pro が必要です。
  • 文字起こしが生成されているか確認してください。
  • デバイスの空き容量が十分か確認してください。

リワード広告または追加の変換▼

  • 1日の追加変換には、リワード広告を最後まで視聴することと、通常はインターネット接続が必要です。
  • 広告を途中で閉じると、特典が付与されないことがあります。
  • 変換回数の制限をなくし、アプリ内広告を消すには Pro にアップグレードしてください。

購入またはサブスクリプションの問題▼

  • 設定 →「Pro を入手」から、月額サブスクリプションまたは生涯購入を選べます。
  • 月額サブスクリプションは、請求期間が終わる少なくとも24時間前に解約しない限り自動更新されます（Apple ID のサブスクリプション設定で管理します）。
  • Pro が認識されない場合は、購入を復元を使ってください。
  • 正しい Apple ID でサインインしているか確認してください。
  • 返金とサブスクリプションの変更は Apple サポートが対応します。

アプリがクラッシュする、または動作が重い▼

  • デバイスを再起動してください。
  • iOS のバージョンが App Store の要件を満たしているか確認してください。
  • バックグラウンドのアプリを終了して、メモリを空けてください。
  • 必要であればアプリを再インストールしてください。
  • 解消しない場合はサポートへご連絡ください。
