英語から IPA への変換の流れ

Phonetic Formatter が、英語の文章全体を数秒で構造化された IPA の文字起こしに変える様子をご覧ください。

IPA（国際音声記号）とは？

国際音声記号（IPA）は、話される言語の音を表す体系です。 つづりではなく、単語が実際にどう発音されるかを示します。

例：through /θruː/  ·  thought /θɔːt/

IPA の文字起こしについて詳しく

各 IPA 記号は特定の音に対応し、言語を超えて発音を明確に、一貫して表します。

英語から IPA への変換ツールは、書かれたテキストを音標に変え、 学習者、教師、言語学者が発音をより効果的に学べるようにします。

このツールは CMU Pronouncing Dictionary を使用します。IPA 変換はデバイス上で完全にオフラインです。

IPA 文字起こし機能の詳細

各機能が何をするか、なぜ役立つか、実際の授業、学習、言語分析の流れのどこに入るかを説明します。

文単位の IPA 文字起こし

句読点、空白、自然な文の区切りを保ったまま、文や段落全体を構造化された IPA に変換します。

単語をひとつずつ引くツールとは異なり、連続したテキストをまとめて処理するため、長い文章でも実際の言語の流れが保たれます。

略語、数字、百分率、混在する句読点も、文字起こしの前に手で整える必要はありません。 名前、数字、略語、見慣れない語を含む実際の文章については、 IPA 変換で未知の語がどう扱われるかを見る →

単語だけを扱うのではなく、実際の授業資料、読解文、言語データの作業に向いています。

単語ごとの IPA 整列

各単語とその IPA が左右に並び、つづりと発音の対応がすぐに分かります。

この整列表示は、文全体の文脈を保ったまま、単語レベルの発音を理解しやすくします。

発音の型を教える、ワークシートを作る、文脈の中で強勢や音節の構造を分析するときに特に役立ちます。

各単語を元の文に結びつけたまま、単語レベルの詳しい確認もできます。 ガイド：単語ごとの IPA レイアウトが教師に役立つ理由 →

読みやすく構造化された IPA の整形

読む、注釈する、授業で使うために整った IPA を出力します。

一貫した間隔、強勢記号、句読点の保持により、長い文章でも見た目が明確で読み取りやすくなります。

生の文字起こしではなく、学習資料、講義ノート、言語の記録に向いた形式です。

音声学の専門家だけでなく、教える人と学ぶ人のどちらにも使える IPA になります。

書類のスキャンと OCR によるテキスト取り込み

カメラボタンをタップして書類をスキャンするか、ライブラリから写真を選びます。 英語のテキストは、Apple の Vision フレームワークにより、すべて端末内で認識されます。

認識されたテキストは入力欄に入り、IPA の文字起こしを生成する前に編集できます。 画像やテキストが当社のサーバーにアップロードされることはありません。

印刷されたワークシート、教科書のページ、手書きのメモを、長い文章を打ち直さずにデジタル化するのに向いています。

オフラインの IPA 文字起こしとプライバシー

音標の文字起こしは端末内で行われ、テキストのクラウド処理はありません。

テキストはローカルで処理され、当社のサーバーにアップロードされないため、プライバシーが重要な環境や組織での利用に向いています。

オフラインでも、文字起こしは速く、安定して動作します。

信頼性やデータの独立性を求める教室、フィールド調査、専門的な作業に向いています。

使い方

英語のテキストを、数秒で構造化された IPA に変換します。

  1. 英語のテキストを貼り付け、入力、またはスキャン — 直接入力するか、書類をスキャンするか、写真を取り込んで端末内の OCR を使います（英語のみ）。
  2. IPA の文字起こしを生成 — アプリがテキストを処理し、CMU 発音辞書に基づく構造化された音標を出力します。
  3. 別の発音を確認 — 別の発音を見て、コピーと書き出しに使う読みを選べます。
  4. 結果をコピーまたは書き出し — 文字起こしをコピーするか、学習資料や授業用に TXT、DOCX、PDF として書き出します。

よくある質問

英語の段落全体を IPA に変換するには？

Phonetic Formatter を開き、テキストを貼り付け、スキャン、または入力して「変換」をタップします。CMU Pronouncing Dictionary を使い、文章全体を一度に文字起こしします。文単位の出力か、Pro では単語ごとの整列を選べます。結果はコピーするか、TXT、DOCX、PDF に書き出せます。

iOS 向けのオフライン IPA 変換はありますか？

音標変換はインターネットなしで 100% 端末内です。テキストはローカルで処理され、当社のサーバーにアップロードされません。教室、移動中、通信が不安定な場所でも使えます。

iPad でも使えますか？もう一度支払う必要はありますか？

使えます。アプリは iPad に合わせてあります。iPhone で Pro をすでに購入している場合は、iPad で同じ Apple ID にサインインし、「購入を復元」を使えば、追加料金なしで Pro の機能を有効にできます。

注：プライバシーを守るため、アプリは文字起こしの履歴を保存しません。処理はすべてその場で、ローカルに行われます。

この変換は CMU Pronunciation Dictionary を使っていますか？

はい。北米英語の自然言語処理で基準とされる CMU Pronunciation Dictionary を使用しています。文単位の文字起こしと強勢の表示のために、独自の処理を加えています。

オンラインの IPA 変換とオフラインアプリ、どちらを使うべきですか？

オンラインの IPA ツールは、すばやい検索や柔軟な音標の選択肢に向いています。Phonetic Formatter のようなオフラインアプリは、文章全体、構造化された整形、プライバシーを重視する作業に向いています。Phonetic Formatter とオンライン IPA ツールの比較をご覧ください。

iPhone と iPad で、教師に最適なオフライン IPA アプリは？

文章全体から授業資料をいつも作るなら、構造化された出力のあるオフラインアプリが向いています。Phonetic Formatter は、iPhone と iPad でこの作業のために作られており、端末内の処理と書き出しに対応します。教師向けの実践ガイドをご覧ください。

スキャン / OCR の取り込みはどのように動作しますか？

カメラボタンをタップして書類をスキャンするか、写真を選びます。テキストはデバイス上で認識され（英語のみ）、入力欄に挿入されます。文字起こしの前に編集できます。テキストが当社のサーバーに送られることはありません。
