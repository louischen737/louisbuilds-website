工作原理

TransMov 通过逐帧处理，将视频转换为 APNG、GIF、WebP 等动图格式。每一帧在本地使用 Apple Vision 分析、去除背景并保留清晰边缘。

与云端工具不同，一切都在你的 Mac 上完成：处理更快、无需上传、视频文件完全私密。

想了解格式差异，可阅读我们的 APNG 与 GIF 对比说明。

常见问题

在 macOS 上如何把视频转成 APNG？

在 TransMov 中导入视频，选择 APNG 为输出格式并导出即可，全部在 macOS 本地完成处理。

GIF 支持透明吗？

GIF 仅支持 1 位透明（全有或全无），容易产生锯齿。APNG 和 WebP 支持完整 Alpha 透明，效果更平滑自然。

APNG 和 GIF 有什么区别？

APNG 支持全色和 Alpha 透明，GIF 仅 256 色和简单透明。APNG 动图质量更高，尤其适合 UI 和渐变内容。

能在 Mac 上本地去除视频背景吗？

可以。TransMov 使用 Apple Vision 在设备端处理，无需上传即可去除视频背景，兼顾隐私与速度。

哪种格式最适合网页动图？

视需求而定：GIF 兼容最广，APNG 透明质量更好，WebP 压缩率常更优。做 UI 与设计素材时，多选 APNG 或 WebP。
