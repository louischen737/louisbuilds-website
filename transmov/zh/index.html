常见问题

在 macOS 上如何把视频转成 APNG？

导入视频，选择 APNG 输出并导出即可。整个过程都在 macOS 本地完成。

GIF 支持透明吗？

GIF 仅支持 1-bit 透明（要么完全透明要么不透明），边缘容易出现锯齿。APNG 与 WebP 支持完整 Alpha 透明，效果更自然。

APNG 和 GIF 的区别是什么？

APNG 支持全彩色与完整 Alpha 透明；GIF 仅支持 256 色与基础透明，画质差距明显。对 UI 和渐变内容，APNG 通常质量更高。

可以在 Mac 本地移除视频背景吗？

可以。TransMov 使用 Apple Vision 在本地处理，无需上传文件，兼顾隐私安全与处理速度。

网页动效选哪种格式更好？

取决于需求：GIF 兼容广，APNG 透明质量更好，WebP 常有更优压缩率。UI 和设计资产一般优先 APNG 或 WebP。
