よくある質問

約 3MB のアプリで、なぜ高品質なアニメーションが作れるのですか？

ダウンロードが小さいからといって、品質が落ちるわけではありません。TransMov は macOS 向けにネイティブ開発しているため、大きなクロスプラットフォーム実行環境を同梱する必要がありません。アプリは軽量なまま、アニメーションをなめらかにプレビューし、APNG、GIF、WebP への書き出しまで、すべて Mac 上で行えます。

macOS で動画を APNG に変換するには？

動画を TransMov に読み込み、出力形式に APNG を選び、書き出すだけで変換できます。処理はすべて macOS 上でローカルに行われます。

GIF は透明に対応していますか？

GIF は 1-bit 透明（完全にオンかオフ）のみで、エッジがギザギザになりやすいです。APNG や WebP はフルアルファ透明に対応し、よりなめらかで自然な結果になります。

APNG と GIF の違いは何ですか？

APNG はフルカラーとアルファ透明に対応し、GIF は 256 色と基本的な透明に限られます。とくに UI やグラデの多いコンテンツでは、APNG のほうが高品質なアニメーションになります。

Mac 上で動画の背景をローカル削除できますか？

はい。TransMov は Apple Vision フレームワーク と端末内処理で、ファイルをアップロードせずに動画の背景を削除します。プライバシーと処理速度を両立できます。

Web アニメーションに最適な形式はどれですか？

用途によります。GIF は互換性が広く、APNG は透明ありで画質が優れ、WebP は多くの場合圧縮効率が高いです。UI やデザイン素材では、APNG または WebP が選ばれがちです。
